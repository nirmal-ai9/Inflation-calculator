# 📈 Inflation Calculator

A modern web-based inflation calculator that shows how money changes in value over time using compound inflation.

---

## ✨ Features

- Calculate future equivalent values using annual inflation.
- View values year by year.
- Animated growth table with progress bars.
- Indian currency formatting (₹).
- Responsive design.
- Modern dark theme.

---

## 📖 Formula

Future value is calculated using compound inflation:

```text
Value = Amount × (1 + Inflation Rate / 100)^(Year − Base Year)
```

### Example

```text
₹100,000 in 2026
6% annual inflation
After 5 years

₹100,000 × (1.06)^5 = ₹133,823
```

## 🚀 Usage

1. Enter the annual inflation rate.
2. Enter an amount.
3. Enter the reference year.
4. Select a start year and end year.
5. Click **Calculate**.
